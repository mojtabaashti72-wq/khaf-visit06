# سامانه بازدید املاک — شهرداری خواف

برنامهٔ تحت وب (فایل واحد) برای ثبت بازدید املاک، کروکی، گزارش رسمی (چاپ/PDF)، برنامه‌ریزی بازدیدها و تقویم کاری.

## امکانات
- ثبت پرونده‌های بازدید همراه عکس، کروکی و مختصات UTM
- گزارش نهایی با امضای کارشناس (امضا از «پروفایل من» ثبت می‌شود)
- برنامه‌ریزی بازدیدها و تقویم کاری
- پشتیبان‌گیری و بازیابی کامل (پرونده‌ها، پروفایل، برنامه‌ها، تنظیمات)
- نصب روی گوشی (PWA) و کار آفلاین

## انتشار روی GitHub Pages
1. مخزن جدید بسازید و همهٔ فایل‌های این پوشه را در شاخهٔ `main` آپلود کنید.
2. به **Settings ← Pages** بروید.
3. در **Build and deployment** گزینهٔ **Deploy from a branch** را انتخاب کنید؛ شاخهٔ `main` و پوشهٔ `/ (root)` را بزنید و ذخیره کنید.
4. پس از چند دقیقه، نشانی `https://USERNAME.github.io/REPO/` فعال می‌شود.

## فایل‌ها
| فایل | کاربرد |
|---|---|
| `index.html` | خود برنامه |
| `manifest.webmanifest` و `icon-*.png` | نصب روی گوشی (PWA) |
| `sw.js` | کار آفلاین |
| `logo-khaf.png` | لوگوی شهرداری |
| `khaf-banner.jpg` | تصویر سربرگ صفحهٔ اصلی |
| `vazirmatn.css` و `vazirmatn.woff2` | فونت وزیرمتن (بدون نیاز به اینترنت) |
| `.nojekyll` | جلوگیری از پردازش Jekyll |

## نکته‌ها
- داده‌ها فقط در حافظهٔ مرورگر کاربر ذخیره می‌شود و روی سرور GitHub قرار نمی‌گیرد. برای جابه‌جایی بین دستگاه‌ها از «پشتیبان کامل» استفاده کنید.
- فایل پشتیبان حساب‌ها شامل رمز عبور است؛ آن را عمومی نکنید و در مخزن قرار ندهید.
- پس از هر به‌روزرسانی، اگر نسخهٔ قدیمی نمایش داده شد، عدد `CACHE` را در `sw.js` تغییر دهید (مثلاً `khaf-v3`).
- نقشه، جستجوی نشانی و ساخت Shapefile به اینترنت نیاز دارند.
